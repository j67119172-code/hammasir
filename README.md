- English: https://j67119172-code.github.io/hammasir/en/

## Safe installation / نصب ایمن
1. First inspect the existing repository and preserve its current files. Download a ZIP backup from Code > Download ZIP before replacing anything.
2. Do NOT delete the existing Android app source, workflows, releases, or APKs. If the repository hosts the app itself, consider deploying this website from a dedicated `gh-pages` branch instead of replacing its main branch.
3. The files in this archive are an independent static site. Copy their contents (not the enclosing folder) into the chosen publishing branch root.
4. Set Settings > Pages > Deploy from a branch > publishing branch > /(root).
5. Verify both /fa/ and /en/ pages before submitting links to Cafe Bazaar.
6. Update real support contact, privacy terms, refund policy, and actual payment behavior before publishing.

No backend, payment integration, or GitHub repo changes are bundled.
